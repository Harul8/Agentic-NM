# Nyaymalaw 3.0 — Evaluation Infrastructure

Evaluation framework for the research paper: "Evaluating Safety, Relevance, and Accuracy of AI-Generated Legal Research Output"

## Quick Start

```bash
# 1. Generate sample safety test queries
python -m eval.safety_runner --generate-sample

# 2. Run batch evaluation (full pipeline)
python -m eval.batch_runner --queries eval/data/queries_sample.json --out eval/results/

# 3. Run ablation variants
python -m eval.batch_runner --queries eval/data/queries_sample.json --out eval/results/ --mode faiss_only
python -m eval.batch_runner --queries eval/data/queries_sample.json --out eval/results/ --mode bm25_only
python -m eval.batch_runner --queries eval/data/queries_sample.json --out eval/results/ --mode merged_no_rerank
python -m eval.batch_runner --queries eval/data/queries_sample.json --out eval/results/ --mode no_internet

# 4. Compute retrieval metrics
python -m eval.retrieval_metrics --results eval/results/batch_full_pipeline_*.json
python -m eval.retrieval_metrics --results eval/results/ --compare  # compare ablation modes

# 5. Run safety tests
python -m eval.safety_runner --queries eval/data/safety_queries.json --out eval/results/safety/

# 6. Verify citations
python -m eval.citation_verifier --results eval/results/batch_full_pipeline_*.json
python -m eval.citation_verifier --results eval/results/batch_full_pipeline_*.json --online  # check Indian Kanoon too

# 7. Threshold sweep
python -m eval.threshold_sweep --results eval/results/batch_full_pipeline_*.json --out eval/results/threshold/

# 8. Generate publication figures
python -m eval.generate_figures --results-dir eval/results/ --out eval/figures/

# 9. Generate annotation template for advocates
python -m eval.annotator_agreement --generate-template eval/data/queries_sample.json --out eval/data/annotation_template.json
```

## Directory Structure

```
eval/
  __init__.py
  batch_runner.py           # Runs all queries through the pipeline
  retrieval_metrics.py      # Precision@k, Recall@k, MRR, nDCG@k, AUC
  safety_runner.py          # Adversarial query testing
  citation_verifier.py      # Hallucinated citation detection
  threshold_sweep.py        # Optimal rerank score analysis
  annotator_agreement.py    # Cohen's Kappa, Krippendorff's Alpha
  generate_figures.py       # Publication-quality charts
  README.md
  data/
    queries_sample.json     # 10 sample queries with gold annotations
    safety_queries.json     # Generated by safety_runner --generate-sample
    annotation_template.json # Generated by annotator_agreement
  results/                  # Batch run outputs
    safety/                 # Safety test reports
    threshold/              # Threshold sweep data
  figures/                  # Generated publication figures
```

## Query Format

```json
{
  "id": "q_01",
  "query": "My neighbour encroached my land...",
  "intent": "legal_opinion",
  "result_count": null,
  "domain": "property",
  "complexity": "moderate",
  "jurisdiction": "Karnataka",
  "gold": {
    "bare_acts": [
      {"act_name": "Specific Relief Act, 1963", "section_number": "38", "relevance": "..."}
    ],
    "case_laws": [
      {"case_name": "X v. Y", "year": "2006", "court": "SC", "relevance": "..."}
    ]
  }
}
```

## Ablation Modes

| Mode | FAISS | BM25 | Cross-Encoder | Quality Filters | Internet |
|------|-------|------|---------------|-----------------|----------|
| `full_pipeline` | Yes | Yes | Yes | Yes | Yes |
| `faiss_only` | Yes | No | No | No | No |
| `bm25_only` | No | Yes | No | No | No |
| `merged_no_rerank` | Yes | Yes | No | No | No |
| `no_internet` | Yes | Yes | Yes | Yes | No |
